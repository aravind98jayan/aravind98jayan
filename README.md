## Featured Projects

**[StaticGuard](https://github.com/aravind98jayan/StaticGuard)**
A Python tool I built for static malware triage. It analyses suspicious files without executing them and gives a risk score and verdict for each file.
- Heuristic risk scoring based on multiple file parameters
- Watch-folder mode that continuously monitors a directory once started
- Desktop notification when a critical file is detected
- Supports multiple file types, with more being added
- Lightweight terminal tool with a minimal footprint

**[Slatewire](https://github.com/aravind98jayan/slatewire)**
A local-first Windows desktop app that brings cybersecurity news from global sources into one dashboard. It sorts and enriches stories to help users track emerging threats, with optional AI-generated briefs.
- Aggregates live updates from 41 RSS/Atom feeds across 30 countries, including government CERTs and security research sources
- Organizes stories by severity and category, groups coverage of the same story, and displays where reports originate
- Enriches stories with CISA Known Exploited Vulnerabilities information, including ransomware links and remediation due dates
- Provides full-text search, filters, saved presets, and a local archive for notes and reviewed stories
- Offers optional Gemini-powered briefs and daily digests, plus custom feeds, notifications, and Markdown, CSV, or JSON export
