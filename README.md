## Featured Project

**[StaticGuard](https://github.com/aravind98jayan/StaticGuard)**
A Python tool I built for static malware triage. It analyses suspicious files without executing them and gives a risk score and verdict for each file.
- Heuristic risk scoring based on multiple file parameters
- Watch-folder mode that continuously monitors a directory once started
- Desktop notification when a critical file is detected
- Supports multiple file types, with more being added
- Lightweight terminal tool with a minimal footprint
